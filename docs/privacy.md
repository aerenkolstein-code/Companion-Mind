# Public/private boundary

This repository permits synthetic events, synthetic identities, public-safe case structures, standard-library code, tests and redacted metrics.

It forbids private Raw/L0/chat exports, real relationship or family archives, adult material, medical or financial information, credentials, account identifiers, client data, assessment questions, unpublished manuscripts and internal universe-control metadata.

Public files must not link to private archives. If publication status is uncertain, the material remains private.
