## Implementation and use

```python
from companion_mind.browser_sidecar import parse_dom, replay_captures
captures = parse_dom(synthetic_html)
persistable = [capture.to_dict() for capture in captures]
deduplicated = replay_captures(captures + captures)
```

The parser takes one static HTML string and returns immutable source-local
captures. It recognizes the **synthetic** `data-c1-*` conventions defined in the
versioned profile. These are not observed production ChatGPT selectors.
There is no DOM attach, extension manifest, event loop, clock, mutation observer,
submit hook, staging engine, live mapper, network transport, or Drive writer.
Profile loading and pin verification perform bounded configuration/file reads.
No browser permissions are requested.

Identity is scoped by profile, opaque local account alias, stable/temporary
conversation identity and source message ID. Titles and prose do not supply
identity. Source position is independent of DOM node object identity. Identical
virtualized nodes collapse; equal identities with differing normalized safe
payload/role/order/lifecycle evidence fail CONFLICT. Different IDs at one source
position fail AMBIGUOUS_IDENTITY. Explicit `reconcile_conversation` returns
mapping evidence while leaving temporary and stable captures unchanged. These
are pure fixture operations, not the S1 runtime or cross-process coordination.

Hidden/inert/aria-hidden/inline-style-hidden branches, scripts, templates and
non-message UI are excluded. Computed CSS, shadow DOM, accessibility-tree
behavior and unspecified markup are outside this synthetic contract. Malformed
HTML, unknown versions, unsupported modes, ambiguous roles, missing identity,
partial selector drift and inconsistent terminal evidence fail closed without
returning a partial set.

Visible paragraph/list/code content becomes normalized markdown. Code-block
spacing is retained; prose spacing and Unicode are normalized. Secret scanning
uses the existing A019 declared-pattern scrubber on joined visible characters
**before** markdown rendering, after Unicode and line-ending normalization.
If scrubbing changes that normalized visible content, the entire
payload is conservatively replaced with `[SECRET_REDACTED]`. No raw-payload hash
or unsanitized output copy is retained. This sacrifices surrounding text when
necessary; it is not a general secret-detection/DLP guarantee.

Attachments preserve a safe observed name, optional observed media type, stable
attachment ID and message association. URLs never enter the output. Missing or
query/fragment/userinfo-bearing links are UNAVAILABLE; even a public link is
REFERENCE_ONLY, not proof that a binary was downloaded or archived.

Streaming is a control observation without a terminal candidate. Complete,
partial and failed states require matching explicit fixture terminal evidence
and the calibrated stable interval. Failed-with-usable-text is ambiguous;
UNKNOWN never becomes a canonical status. `data-c1-stable-ms` is supplied
synthetic evidence, not a measured browser duration. Every output says
`SOURCE_LOCAL_ONLY`, `canonical_commit=false`, `ingest_state=NOT_ATTEMPTED`.
