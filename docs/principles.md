# Engineering principles

1. **Source before conclusion.** A model or rule output is a candidate until evaluated.
2. **State before prose.** Operational status must not depend on a fluent summary.
3. **Constraint before commitment.** Veto conditions run before a write.
4. **UNKNOWN remains UNKNOWN.** Missing evidence cannot be converted into completion.
5. **Evaluation is explicit.** Every acceptance, rejection or hold has a reason and checks.
6. **Errors consolidate into regressions.** A corrected failure must become executable.
7. **Activation is not participation.** Stored knowledge matters only when it affects the decision.
8. **Budgets and deduplication are part of cognition.** A useful runtime must know when to stop.
