# Problem statement

Retrieval makes history reachable. It does not guarantee that an open dependency, unresolved uncertainty or veto constraint participates before the system commits a new state.

Companion-Mind studies a narrower engineering problem:

> Can a small runtime maintain explicit state, generate a bounded cognitive task, evaluate a candidate against active constraints and leave an auditable trace before writing?

The first closed loop tests one concrete failure: premature parent closure. It does not attempt to simulate a brain, prove consciousness or build a fully autonomous agent.
